# 가쓸신제 — 제주 캠프 학생용 웹앱

「제주! 내가 계획하는 캠프」 2기 (2026. 11. 10.~13.) 학생용 모바일 앱입니다.
일본 수학여행 앱과 같은 저장소·같은 Firebase 프로젝트(`chongsangojapan`)를 쓰지만, 화면과 데이터는 `jeju/` 폴더와 데이터베이스 `jeju/` 위치에 따로 있습니다. 일본 앱에는 영향이 없습니다.

- 주소: **https://chongsangojapan.web.app/jeju/** (main에 반영되면 GitHub Actions가 자동 배포)
- 예비 주소: https://kiseounghong-sketch.github.io/japanchonsan/jeju/ (GitHub Pages)

## 선생님이 처음 할 일 (출발 전 5분)

1. 앱을 열고 **왼쪽 위 로고를 1.5초 길게 누르기** (또는 `안내` 탭 맨 아래 작은 글자를 빠르게 5번)
2. 선생님 비밀번호 입력 → 일본 수학여행 앱과 같은 계정(`teacher@japanchonsan.app`)
3. `선생님` 탭 → **입장 코드 만들기** → **단톡방 안내문 복사** → 단톡방에 붙여넣기
   (링크에 코드가 들어 있어서 학생은 누르기만 하면 됩니다)
4. **공유 설정**에 구글 드라이브 사진 폴더 링크와 선생님 연락처 저장
   (입장 코드가 있는 학생에게만 보이고, 공개 주소·저장소에는 올라가지 않습니다)

## 일정이 바뀌면

`jeju/data/schedule.json`만 고쳐서 main에 올리면 됩니다. 학생 앱은 다음에 열 때(또는 10분 뒤 다시 볼 때) 새 일정을 받아요. 급하면 공지로 먼저 알리세요.

```json
{ "time": "12:40", "end": "13:30", "title": "점심 – 자매국수", "place": "jamae",
  "memo": "고기국수", "type": "meal", "status": "ok", "pay": "self",
  "gather": true, "gatherAt": "동문시장 8번 게이트" }
```

- `type`: `activity` 활동 · `move` 이동(흐리게) · `meal` 식사 · `gather` 집결 · `stay` 숙소
- `status`: `ok` 확정 · `need` 확인 필요 · `tbd` 미정
- `end`가 없으면 다음 줄 시작 시각까지로 계산
- `gather: true`인 줄이 `오늘` 탭 **집결 카운트다운**에 쓰임 (`gatherAt` = 화면에 보일 장소)
- `pay: "self"` → '개인 돈' 표시
- `place` = `places.json`의 `id` (누르면 네이버 지도 앱에서 그 장소가 바로 열림)

다른 파일: `places.json` 장소·주소(`nid` = 네이버 지도 장소 번호 — 네이버 지도에서 장소를 열었을 때 주소 `m.place.naver.com/place/숫자`의 숫자, `naver` = 번호가 없을 때 쓸 검색어) · `rules.json` 안전 규칙 · `contacts.json` 비상 연락 · `checklist.json` 준비물 · `missions.json` 미션 · `roles.json` 역할 · `shots.json` 촬영 목록 · `info.json` 개인 돈·대안·제출물 · `camp.json` 기본 정보

## 미리 보기

주소 끝에 `?now=2026-11-10T17:35`를 붙이면 그 시각인 것처럼 `오늘` 탭을 볼 수 있습니다 (위에 노란 줄 표시).

## 동작 방식

- 서버 없는 정적 앱(HTML/CSS/JS). 시간은 기기 시간대와 상관없이 **한국 시간** 기준
- 한 번 열면 서비스워커가 저장 → 비행기·해안·차귀도에서 인터넷 없이도 일정·안전 정보가 보임
- 준비물 체크·미션 답·소감은 **먼저 각자 폰에 저장**되고, 입장 코드가 있으면 인터넷이 될 때 선생님께 자동 공유
- 카카오톡 안에서 열면 서비스워커가 안 될 수 있어 '다른 브라우저로 열기' 안내가 뜸 → 홈 화면에 추가 권장
- 데이터베이스 규칙(`database.rules.json`의 `jeju`): 입장 코드를 모르면 읽기·쓰기 불가, 공지·인원 점검 시작은 선생님 계정만, 도착 시각은 서버 시각만 허용
